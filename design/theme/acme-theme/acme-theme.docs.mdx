A theme component for using the AcmeTheme Design Language and tokens.

## Get started

To use the AcmeTheme theme in your app, install the theme and apply it on your component tree.
Themes are usually applied on the root of your component tree.

```tsx
import { AcmeTheme } from '@acme-modular/design.theme.acme-theme'

export function MyApp() {
  return (
    <AcmeTheme>
      <Homepage />
    </AcmeTheme>
  );
}
```
